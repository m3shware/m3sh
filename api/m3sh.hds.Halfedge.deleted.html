m3sh.hds.Halfedge.

deleted#

Halfedge.deleted#

Internal state.

Topological mesh modification (e.g., edge conctractions) may render halfedges as deleted when they do no longer contribute to a mesh’s combinatorics.

Notes

The halfedge dictionary halfedges of a mesh will never contain deleted halfedges.
